# Sun Drenched

A responsive swimwear website prototype built from the supplied Sun Drenched homepage wireframe and photography.

Live site: https://nicrios.github.io/sundrenched/

## Local development

This is a buildless HTML, CSS, and JavaScript site.

```sh
python3 -m http.server 4177 --bind 127.0.0.1
```

Open http://127.0.0.1:4177/.

## Structure

- `index.html`: utility navigation, collection cards, ocean and community stories, promotional banner, footer, and accessible content dialogs.
- `shop.html`: 20-product shop grid with product photos, names, and prices; every card links to that product's page. `jewelry.html` and `wetsuits.html` use the same grid with that collection first. All three use the same utility navigation, header, footer, and dialogs as the homepage.
- `<product-name>.html` (20 pages, for example `always-sunny-bikini-set.html`): product pages with the photo, price, collapsible details, a review summary, and a "You may also like" row that starts with other pieces in the same category. They are generated by `tools/build_product_pages.py` from `shop.html`'s header, footer, and dialogs. To change product copy, prices, or related items, edit that script and re-run `python3 tools/build_product_pages.py`.
- `assets/css/styles.css`: reference palette, typography, responsive layouts, and logo framing.
- `assets/js/main.js`: mobile navigation, local collection/story search, and dialog controls.
- `assets/images/`: supplied product, lifestyle, and underwater photography. `brand-reference.png` preserves the supplied artwork; CSS frames the original header and footer logos without recreating them.
- `.github/workflows/pages.yml`: publishes every top-level `.html` page and `assets/` to GitHub Pages.

The layout follows the wireframe on desktop and tablet, including the source-specific photo crops. Photos use the palette brown at 20% opacity, with 30% on the hero and 50% on the mobile jewelry card. DynaPuff is used as a close visual match for the reference headings; the original heading font was not supplied. Below 641px, navigation collapses to a menu, product cards use two columns, and editorial sections stack. The shop uses four product columns above that breakpoint. Shop navigation and homepage promotions link to `shop.html`; on the homepage the Swimwear card links to `shop.html`, the Wetsuits card to `wetsuits.html`, and the Jewelry card to `jewelry.html`. Collection previews remain available through search. Editorial buttons open previews, and email links launch the visitor's mail app. Utility social icons open Instagram, TikTok, and X; replace those platform URLs when brand profiles are available. This prototype has no checkout, payments, accounts, inventory, or form backend; Add To Cart on a product page only shows a prototype message. The displayed products, prices, collection and promotional text are design copy, as are the product descriptions, sample review counts, sizing, shipping, and return text on the product pages.

## Publication and checks

Use a feature branch and pull request. Merging to `main` deploys the site through the existing Pages workflow.

For layout changes, check 390px, 768px, and 1440px widths, verify every image loads, and exercise the menu, dialogs, Escape behavior, internal links, and footer links. Use `node --check assets/js/main.js` and `git diff --check` for the affected source.
